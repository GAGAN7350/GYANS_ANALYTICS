Project Details
• Title of the Project: GYAN ANALYTICS
• Project Domain/Area: Business Intelligence (BI), Data Analytics & Visualization, Full-Stack Web Development
• Problem Statement & Objectives:
Problem Statement:

Commercial Business Intelligence (BI) platforms (such as Microsoft Power BI, Tableau, and Zoho Analytics) are predominantly proprietary, expensive, cloud-tethered, and enforce recurring per-user licensing fees. Organizations, academic institutions, and small-to-medium enterprises dealing with sensitive operational data face critical data privacy risks, vendor lock-in, and steep infrastructure expenses. Furthermore, existing open-source alternatives often present steep learning curves, require complex deployment configurations, and lack an integrated, intuitive drag-and-drop dashboard design and ETL (Extract, Transform, Load) environment.

Objectives:
  1. To design and implement a secure, lightweight, and self-hosted full-stack Business Intelligence web platform with zero licensing cost.
  2. To provide versatile data ingestion modules supporting multi-format files (CSV, Excel, JSON) and relational databases (PostgreSQL / SQLite).
  3. To build an interactive, visual drag-and-drop dashboard composer supporting 15+ real-time charting widgets (Bar, Line, Area, Pie, KPI cards) using Apache ECharts.
  4. To incorporate automated schema detection, visual ETL data preparation, and secure Role-Based Access Control (RBAC).
• Proposed Technology/Tools:
  • Frontend: React.js 18, TypeScript, Vite, Ant Design 5 (Enterprise Components), Zustand (State Management)
  • Visualization Engine: Apache ECharts, Recharts (Dynamic interactive charts)
  • Backend API: Python 3.12, FastAPI (Asynchronous REST API framework), Pydantic v2
  • Data Processing & ORM: Pandas, SQLAlchemy 2.0 (Async), Alembic (Database Migrations)
  • Database: SQLite (Local Development) / PostgreSQL 16 (Production)
  • Security & Auth: OAuth2 with JWT (JSON Web Tokens), Bcrypt Password Hashing, RBAC (Admin, Editor, Viewer)
  • DevOps & Tooling: Docker, Docker Compose, Nginx Reverse Proxy, Git/GitHub, Postman, VS Code
• Brief Abstract (150-200 words):

GYAN Analytics is an open-source, self-hosted Business Intelligence (BI) and data visualization platform developed to deliver enterprise-grade reporting and dashboard capabilities with zero software licensing costs and complete data sovereignty. As contemporary enterprises and academic institutions generate substantial volumes of diverse data, deriving actionable insights typically requires costly commercial software that compromises on-premise data control. GYAN Analytics addresses this challenge through a robust, asynchronous architecture comprising a Python FastAPI backend, a responsive React-TypeScript frontend, and a flexible relational storage layer. The platform facilitates direct ingestion from file uploads (CSV, Excel, JSON) and relational database sources, features automated schema detection and data cleaning workflows, and offers an intuitive drag-and-drop dashboard builder powered by Apache ECharts. Integrated with Role-Based Access Control (RBAC), secure JWT token management, and embeddable visual reporting, the system guarantees high throughput, low latency, and uncompromising privacy. By providing a modular, containerized alternative to proprietary BI platforms like Power BI and Zoho Analytics, GYAN Analytics establishes an accessible, scalable solution for modern operational intelligence.

• Expected Outcome:
  1. A fully functional, responsive web application enabling authenticated users to upload, query, and transform datasets.
  2. An interactive dashboard composer allowing users to create, configure, save, and export multi-chart analytics views (PDF/PNG).
  3. Secure multi-tenant workspace architecture with granular access tiers (Admin, Editor, Viewer) and encrypted credentials.
  4. A modular, containerized deployment package (via Docker Compose) enabling single-command deployment across diverse operating systems.
